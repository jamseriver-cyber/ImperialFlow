# 接入模板

本目录是待填写模板，不构成真实 Task、启动授权、角色指派、方案批准、执行授权或验收。保留占位符直到有实际证据，不能为让流程看起来完整而补造后续决定。

| 文件 | 用途 |
| --- | --- |
| [AGENTS.md](AGENTS.md) | 新项目行为入口，按实际路径与 Runtime 接入方式调整 |
| [task_evidence.md](task_evidence.md) | 只追加历史过程与证据 |
| [plan.md](plan.md) | 中书方案输入输出、方法与验收 |
| [review.md](review.md) | 门下对当前方案的独立审查 |
| [execution_package.md](execution_package.md) | 尚书准备职责、范围与停止条件 |
| [validation.md](validation.md) | 刑部对实际交付的独立验证 |

复制到新项目前，确定风险、可信身份来源、真实 START_TASK 和当前路由。模板中示例格式与合成测试都不是实际决定。初版不提供通用 Registry 初始化器，接入说明见 [Runtime](../docs/runtime.md)。
